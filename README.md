# 奇门遁甲时间显示应用

## 应用介绍

这是一款集成了奇门遁甲排盘功能的时间显示应用，不仅能显示当前时间，还能根据实时八字数据计算奇门遁甲排盘，并提供运势分析和详细解读。

## 核心功能

- **实时时间显示**：七段数码管风格的时间显示
- **八字计算**：基于当前时间准确计算年、月、日、时四柱
- **奇门遁甲排盘**：自动计算阴阳遁、用局数，排定九星八门
- **运势分析**：基于排盘结果生成综合运势评估和建议
- **详细解读**：点击九宫格查看专业的奇门遁甲解读

## 计算规则

### 1. 八字计算规则

#### 年柱计算
- 以立春为年分界点
- 1900年为庚子年，以此为基准计算

#### 月柱计算
- 以节气为月分界点（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）
- 使用五虎遁诀计算月干

#### 日柱计算
- 基于1900年1月1日（甲午日）为基准
- 考虑闰年因素，准确计算日干支

#### 时柱计算
- **时间范围**：子时(23:00-01:00)、丑时(01:00-03:00)、寅时(03:00-05:00)、卯时(05:00-07:00)、辰时(07:00-09:00)、巳时(09:00-11:00)、午时(11:00-13:00)、未时(13:00-15:00)、申时(15:00-17:00)、酉时(17:00-19:00)、戌时(19:00-21:00)、亥时(21:00-23:00)
- **分钟规则**：45分钟为界，45分前属于当前时辰，45分后进入下一个时辰
- **夜子时**：23:00-00:00属于夜子时，计入次日的子时
- **日上起时法**：甲己起甲子，乙庚起丙子，丙辛起戊子，丁壬起庚子，戊癸起壬子

### 2. 奇门遁甲排盘规则

#### 阴阳遁判断
- 阳遁：寅、卯、辰、巳、午、未月
- 阴遁：申、酉、戌、亥、子、丑月

#### 用局数计算
- 基于传统奇门遁甲用局表：
  - 子月：1局
  - 丑月：8局
  - 寅月：1局
  - 卯月：3局
  - 辰月：4局
  - 巳月：6局
  - 午月：9局
  - 未月：2局
  - 申月：9局
  - 酉月：7局
  - 戌月：6局
  - 亥月：4局

#### 九星排布
- 阳遁：顺排九星
- 阴遁：逆排九星

#### 八门排布
- 阳遁：顺排八门
- 阴遁：逆排八门

#### 八神排布
- 阳遁：顺排八神
- 阴遁：逆排八神

### 3. 运势分析规则

#### 整体运势评估
- **运势上扬**：吉门数量≥3（生门、休门、开门）
- **运势平稳**：吉门数量1-2
- **运势低迷**：吉门数量=0

#### 贵人方位确定
- 基于值符星所在宫位确定贵人方位
- 值符星是奇门遁甲中最吉的神，所在方位易得助力

#### 建议生成
- **运势上扬**：把握局数优势，主动出击，宜向吉方发展
- **运势平稳**：稳步前行，抓住机遇，防范风险
- **运势低迷**：养精蓄锐，守正出奇，等待时机

## 界面说明

### 主界面
- **时间显示**：七段数码管风格的当前时间
- **日期显示**：当前日期和星期
- **八字显示**：当前的年、月、日、时四柱
- **九宫格**：显示奇门遁甲排盘结果
- **当前运势**：基于排盘的综合运势分析

### 详细解读
- 点击九宫格显示详细的奇门遁甲解读
- 包含阴阳遁、用局数、吉方凶方、时间建议、事项建议等
- 使用专业术语提供深入分析

## 技术实现

- **开发语言**：Java
- **界面设计**：自定义View组件
- **计算核心**：基于传统奇门遁甲算法
- **时间更新**：每秒自动更新，时辰变化时重新计算

## 使用方法

1. **查看当前时间**：主界面实时显示当前时间
2. **查看运势**：主界面底部显示当前运势分析
3. **详细解读**：点击九宫格查看专业解读
4. **时间调整**：应用会自动跟随系统时间变化

## 注意事项

- 运势分析仅供参考，实际决策还需结合自身情况
- 时辰交替时（45分后）运势会自动更新
- 不同时间点的排盘结果不同，运势分析也会相应变化
