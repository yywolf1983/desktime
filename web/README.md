# 奇门遁甲时家转盘排盘算法说明

本目录是「奇门遁甲时间显示」的 **Web 计算引擎**，全部算法集中在 `qimen.js`
（唯一权威实现）。输入一个 `Date`，输出完整的时家转盘奇门局（九宫八方的星、门、神、天地盘干、旺衰、吉凶）。

算法已与 Android 端 `QiMenCalculator` / `JieqiData` 逐项核对一致。

---

## 0. 流派与算法定位

本引擎属于 **时家奇门遁甲** 体系，具体采用以下组合：

- **时家（时盘）**：按「时辰」起局。值符 / 值使由**时柱干支**定旬首，而非日家 / 月家 / 年家。
- **转盘法（非飞盘）**：九星、八门、八神均以值符 / 值使所在宫为起点，按九宫顺序**顺排（阳遁）或逆排（阴遁）**旋转布盘；不是按洛书轨迹跳宫的飞盘派。
- **拆补法定局**：用局只看「当前节气 + 节气内第几天」的三元划分（第 1–5 天=上元、6–10 天=中元、11–15 天=下元），直接查局数表，**不做置闰**。相对的是置闰法（超神接气、加闰奇）与茅山法（三元边界划分不同）。
- **中宫寄坤**：中五宫不排门 / 神（八门八神不入中宫）；甲辰旬落中宫时值使门寄**坤二宫·死门**，为转盘法标准寄宫处理。
- **局数表**：`YANG_DUN_JU` / `VIN_DUN_JU`（冬至阳遁 1·7·4、夏至阴遁 9·3·6 …）为传统时家转盘的**标准用局表**（常称「茅山局数 / 常规局」），与转盘法配套。

一句话：**时家转盘奇门 · 拆补法起局 · 中宫寄坤二宫**。

## 2. 四柱（年/月/日/时干支）

四柱是后面所有计算的输入，约定如下（均以 **App 为准**）：

### 2.1 年柱 `calculateYearPillar`
- 取该时刻**正午 12:00** 所在节气；若处在 **小寒 / 大寒**（冬至后、立春前），年份减 1，属上一年。
- 以 1900 年为基准：`LIUJIAZI[(36 + (年 - 1900)) % 60]`。
  （注：这里刻意不用「立春为界」，以与 App 完全一致。）

### 2.2 月柱 `calculateMonthPillar` + `getMonthZhi`
- **月支按节气（节月）定**，而非阳历月份：

  | 节气区间 | 月支 | 节气区间 | 月支 |
  |---|---|---|---|
  | 立春/雨水 | 寅 | 立秋/处暑 | 申 |
  | 惊蛰/春分 | 卯 | 白露/秋分 | 酉 |
  | 清明/谷雨 | 辰 | 寒露/霜降 | 戌 |
  | 立夏/小满 | 巳 | 立冬/小雪 | 亥 |
  | 芒种/夏至 | 午 | 大雪/冬至 | 子 |
  | 小暑/大暑 | 未 | 小寒/大寒 | 丑 |

- **月干**用「五虎遁」：`甲己→丙、乙庚→戊、丙辛→庚、丁壬→壬、戊癸→甲`，从寅月顺推。

### 2.3 日柱 `calculateDayPillar`
- 用**儒略日整数差**避免夏时制误差：`(儒略日(年,月,日) − 儒略日(1900,1,1))` 为天数差。
- 以 1900-01-01 为**甲戌日**（序号 10）：`LIUJIAZI[(10 + 天数差) % 60]`。

### 2.4 时柱 `calculateTimePillar`
- **时辰**：子=23:00~01:00、丑=01:00~03:00 … 亥=21:00~23:00（左闭右开，子时跨 0 点）。
- **不做 45 分进位**（与 App 一致，即 23:44 仍属子时，不进丑时）。
- **时干**用「五鼠遁」：`甲己→甲、乙庚→丙、丙辛→戊、丁壬→庚、戊癸→壬`，从子上起。
- **夜子时顺延**：当 `hour >= 23`（子时），日柱与时柱按**次日**计算（日数 +1，必要时跨月/跨年）。

> 四柱中「年柱、月柱」用原日期；「日柱、时柱」在 `hour>=23` 时改用次日日期。

## 3. 节气（寿星公式）`getJieqiDate` / `getCurrentJieqi`

- 24 节气日期由**寿星公式**给出：`day = floor(年尾数×0.2422 + C) − floor((年尾数−1)/4)`，
  常数 `C` 分 20 世纪（`year20`）与 21 世纪（`year21`）两套（立秋常数已修正为 8.35）。
- `getCurrentJieqi(year,month,day,hour)` 取各节气**正午 12:00** 为界，
  判定给定时刻落在哪个节气区间内（冬至→小寒→大寒→立春→…→大雪→冬至）。
- `getDaysIntoJieqi(...)` 返回该日处于当前节气内的**第几天（0 基，0..14）**，用于三元定局。

## 4. 阴阳遁 / 用局数

- **阴阳遁**：冬至、小寒、大寒、立春、雨水、惊蛰、春分、清明、谷雨、立夏、小满、芒种 → **阳遁**；
  夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪 → **阴遁**。
- **三元**：节气内第 1–5 天为上元，6–10 天为中元，11–15 天为下元。
- **用局表**（`[节气][上/中/下元]`）：

  阳遁：

  | 冬至 | 小寒 | 大寒 | 立春 | 雨水 | 惊蛰 | 春分 | 清明 | 谷雨 | 立夏 | 小满 | 芒种 |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 1·7·4 | 2·8·5 | 3·9·6 | 8·5·2 | 9·6·3 | 1·7·4 | 3·9·6 | 4·1·7 | 5·2·8 | 4·1·7 | 5·2·8 | 6·3·9 |

  阴遁：

  | 夏至 | 小暑 | 大暑 | 立秋 | 处暑 | 白露 | 秋分 | 寒露 | 霜降 | 立冬 | 小雪 | 大雪 |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 9·3·6 | 8·2·5 | 7·1·4 | 2·5·8 | 1·4·7 | 9·3·6 | 7·1·4 | 6·9·3 | 5·8·2 | 6·9·3 | 5·8·2 | 4·7·1 |

  例如：夏至第 3 天（上元）→ 阴遁九局；立春第 12 天（下元）→ 阳遁二局。

## 5. 地盘（三奇六仪）`arrangeDiPanTianGanStandard`

九宫顺序固定为 **宫序索引 0..8**：

```
0 坎一   1 坤二   2 震三   3 巽四   4 中五   5 乾六   6 兑七   7 艮八   8 离九
```

- **阳遁**：从「局数宫」起**顺排** `戊 己 庚 辛 壬 癸 丁 丙 乙`。
- **阴遁**：从「局数宫」起**逆排** `戊 乙 丙 丁 癸 壬 辛 庚 己`。

内部用 `diPanJu = 阳遁? +ju : −ju` 统一表示方向。

## 6. 旬首 / 值符 / 值使

- **六甲遁于六仪**：甲子→戊、甲戌→己、甲申→庚、甲午→辛、甲辰→壬、甲寅→癸。
- **旬首**：从时柱干支查其所在旬（六十甲子每 10 干为一旬）。
- **值符星** = 旬首六仪在地盘所在宫的「地盘九星」；
  **值使门** = 该宫的「地盘八门」（中宫空时寄 **坤二宫·死门**）。
- **值符落宫（值符随时干）**：取时干在地盘所在宫（时干为「甲」时，改取旬首六仪所在宫）。
- **值使落宫**：从旬首宫起，按 `时支序 − 旬首地支序`（0..11）**阳顺阴逆** 移动
  （步数必须用「时支 − 旬首地支」，否则甲戌等旬会整体错位）。

---

## 7. 天盘 / 九星 / 八门 / 八神

- **天盘三奇六仪** `arrangeTianPanTianGanStandard`：整盘随值符旋转，
  使「旬首六仪」（值符星所携之干）落**值符宫**；余干按 `戊己庚辛壬癸丁丙乙` 顺/逆排。
- **九星** `arrangeNineStarsStandard`：以值符星落值符宫为起点，九星按原序阳顺阴逆布盘。
- **八门** `arrangeEightDoorsStandard`：以值使门落值使宫为起点，八门 `休生伤杜景死惊开`
  阳顺阴逆布盘，**不入中五宫**。
- **八神** `arrangeEightGodsStandard`：以值符落值符宫为起点。
  - 阳遁序：值符·螣蛇·太阴·六合·白虎·玄武·九地·九天
  - 阴遁序：值符·九天·九地·玄武·白虎·六合·太阴·螣蛇
  - 同样**不入中五宫**。

---

## 8. 旺衰 `calculateWangCui`

以**宫五行**为用神、**节气月令五行**为时令：

- 同 → **旺**　月令生宫 → **相**　宫生月令 → **休**　月令克宫 → **囚**　宫克月令 → **死**

月令五行（按节气）：寅卯月木、辰月土、巳午月火、未月土、申酉月金、戌月土、亥子月水、丑月土。
宫五行（宫序 0..8）：水·土·木·木·土·金·金·土·火。

---

## 9. 吉凶评分 `getLuckSymbol`

对每宫的「星 + 门 + 神 + 旺衰」加权求和：

- 星：天辅/天心/天禽 +3，天任 +2，天冲 +1，天英 0，天蓬/天芮/天柱 −2
- 门：开/生 +3，休 +2，景 +1，杜 0，惊 −1，伤/死 −3
- 神：值符 +3，九天/太阴/六合 +2，九地 0，螣蛇 −1，白虎/玄武 −3
- 旺衰：旺 +3，相 +2，休 0，囚 −2，死 −3

总分映射：≥5 大吉、≥3 吉、≥1 平吉、≥−1 平、≥−3 平凶、≥−5 凶、其余 大凶。

## 10. 数据结构

`QiMenCalc.calculate(date)` 返回：

```js
{
  yearPillar, monthPillar, dayPillar, timePillar,   // 四柱
  jieqi, isYangDun, ju, dayInJieqi, daysIntoJieqi, // 节气/局数
  xunShou, xunShouGan, zhiFuStar, zhiShiDoor,      // 旬首/值符/值使
  zhiFuPalace, zhiShiPalace,
  diPanTianGan, tianPanTianGan,                    // 地盘/天盘三奇六仪
  nineStars, eightDoors, eightGods, wangCui, luck, // 九星/八门/八神/旺衰/吉凶
  palaceData[0..8]  // 每宫：宫名/方位/卦符/神/星/门/天盘干/地盘干/吉凶/旺衰
}
```

`palaceData` 索引 0..8 固定为：坎·坤·震·巽·中·乾·兑·艮·离。

## 11. 用法

```html
<script src="qimen.js"></script>
<script>
  const r = window.QiMenCalc.calculate(new Date(2026, 8, 2, 12, 0)); // 2026-09-02 12:00
  console.log(r.yearPillar, r.monthPillar, r.dayPillar, r.timePillar);
  console.log(r.jieqi, r.isYangDun ? '阳遁' : '阴遁', r.ju + '局');
  r.palaceData.forEach(p => console.log(p.palaceName, p.star, p.door, p.god, p.tianGan, p.luck));
</script>
```

其余对外辅助函数：`getCurrentJieqi(date 拆分)`、`getJieqiDate(year, idx)`、`getDaysIntoJieqi(...)`。

## 12. 与 App 的关系

`web/qimen.js` 是 Android 端 `QiMenCalculator` / `JieqiData`（Java）的移植；
四柱、节气、三元局数、地盘、值符值使、天盘、九星八门八神、旺衰、吉凶评分
均按 App 规则实现，因此同一时刻两者排盘结果一致。
